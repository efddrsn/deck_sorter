# Deck Sorter

Design notes for an automatic Magic: The Gathering card scanner feeder.

The current MVP focuses on mechanically presenting one card at a time to an off-the-shelf phone scanner app, then moving the card to a single output tray. Recognition, inventory management, and sorting are intentionally left to existing apps and later iterations.

See [DESIGN_DOC.md](DESIGN_DOC.md) for the full design document.
